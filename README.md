# tg-pptx-bot

Telegram-бот, который по теме от пользователя генерирует структуру презентации
через ИИ (OpenRouter) и собирает готовый `.pptx` файл с помощью `pptxgenjs`.

## Структура проекта

- `index.js` — точка входа: инициализация Telegraf, обработка `/start` и текстовых сообщений.
- `ai.js` — запрос к ИИ (OpenRouter), парсинг и валидация JSON-структуры презентации.
- `presentation.js` — сборка `.pptx` файла из структуры с помощью `pptxgenjs`.
- `.env.example` — шаблон переменных окружения.

## Установка

```bash
npm install
cp .env.example .env
```

Заполни `.env`:

```
BOT_TOKEN=токен_от_BotFather
OPENROUTER_API_KEY=твой_ключ_с_openrouter.ai
OPENROUTER_MODEL=meta-llama/llama-3.1-8b-instruct:free
```

- Токен бота получить у [@BotFather](https://t.me/BotFather).
- Ключ OpenRouter — зарегистрироваться на https://openrouter.ai и создать API key.
  На странице https://openrouter.ai/models?max_price=0 можно выбрать актуальную
  бесплатную модель и вставить её id в `OPENROUTER_MODEL`.

## Запуск

```bash
npm start
```

## Как это работает

1. `/start` — бот приветствует и просит тему.
2. Пользователь пишет тему текстом.
3. `ai.js` отправляет промпт в OpenRouter, требуя строго JSON вида:
   ```json
   {
     "title": "...",
     "slides": [
       { "slideNumber": 1, "title": "...", "bullets": ["...", "..."] }
     ]
   }
   ```
   Модуль сам вырезает JSON из ответа (даже если модель обернула его в
   \`\`\`json ... \`\`\`) и проверяет структуру.
4. `presentation.js` собирает слайды через `pptxgenjs`: титульный слайд +
   слайды с заголовком и буллет-пунктами.
5. `index.js` отправляет готовый файл пользователю и удаляет временный файл.

## Возможные доработки

- Хранить прогресс/очередь в базе данных, если нагрузка вырастет.
- Добавить выбор дизайна/цветовой темы командой.
- Добавить retry с уменьшенным промптом, если ИИ вернул невалидный JSON.
- Ограничить длину темы и добавить простую антиспам-защиту (rate limit).
